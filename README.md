# GlowTrack — Skincare & Wellness Companion

A modern full-stack web application designed for mindful skincare tracking, routine regimens, hydration monitoring, and product curation.

- **Frontend**: React 18, Vite, TailwindCSS (Port `5173`)
- **Backend**: Node.js 24, Express, Atomic Persistent JSON Store (Port `5000`)

---

## Quick Start

To run both backend and frontend together:

```powershell
node start-dev.js
```
Or double-click **`start-dev.bat`** on Windows.

For detailed instructions and options, see [RUN_INSTRUCTIONS.md](file:///c:/Users/dbipa/OneDrive/Desktop/skincare/RUN_INSTRUCTIONS.md).
